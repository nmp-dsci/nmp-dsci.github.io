stale

The page is a version behind, and the story changed

Champion, bundle id, code SHA, the promotion rule, the split table, "six admin pages", "not built: per-call spans" — every one of those is now wrong. Verified against the repo and the live URL, not the README.

The bigger change is the argument: from "GEPA lifted accuracy and the gate refused v3_1" to "a loop that attributes every miss to one agent, changes one agent, and promotes only on evidence the optimiser never saw."

angle

Design that scales, measured honestly — not a bigger number

The headline should be the loop's shape and its refusals, with accuracy as the proof the measurement works. v5's +2.1 pp is not significant (McNemar p=0.50, n=187) and the write-up should say so in the same sentence it reports it.

What earns the claim: sealed holdout (opened 0 times), attribution before change, one lever per challenger, every verdict on an append-only history, served bundle asserted equal to the registry champion.

blocked

  • A deep: key on the project front matter; the layout renders the §3 link from it and the lint checks the target exists.

what to watch

  • Not a second README. The repo README already documents the CLI. The deep page adds what the README cannot: the reasoning, the dated evidence, the log of refusals. Paste only the commands that reproduce a number; link the README for the rest.
  • Drift is the failure mode of a maintained page. The practice page's rule already answers it: every count carries the command and the date it was last re-run.
  • The matrix never links the deep page. The scorecard and card lines stay the case study's job, so the two pages cannot disagree about the headline.
  • Scope now vs later. The collection is a one-off cost; the first deep page is mostly content this artifact already holds (the loop table, the evidence table, the tool table).

risks · what could make the page wrong again

  • Significance. p = 0.50 on 187 questions. Any sentence that says "improved" without "not significant" beside it is the flattering-zero failure the page itself warns about.
  • The Opus teacher that never shipped. The s04 plan and its diagram say Claude Agent SDK / Opus 5; the code says deepseek-v4-pro via pydantic-ai. The page follows the code; the plan is history.
  • Seven pages. Until D5 lands, the live Dataset page is a 500. A claim the smoke test does not assert is a claim a visitor can falsify.
  • Denominators. 770 (corpus), 187 (test-50 shared set), 44 (train-10), 123 (program turns). Every number carries its own.
  • Practice drift. The practice's step 5 and ConvFinQA's rule now disagree; the lint cannot see that, only a reader can.
  • MLflow snapshot has 0 runs. evaluation/mlflow_snapshot.json exports registry and versions only, so the demo Experiments tab shows versions, not runs. Verify in the browser before describing it.
