00

The teardown — what v1 gets right, and what blocks it

Keeping: the measured "Eval Report" voice, metric-first cards, real numbers, light/dark. Those are differentiators — most AI portfolios are vibes. What follows is what stands between v1 and "best page possible."

Blocker

No identity — the logo is a 14px glyph

The brand mark is a tiny ▮ character; the favicon is the same glyph on transparency. Invisible in the nav, invisible in a tab strip, nothing to remember. A portfolio competing for attention needs a mark that survives a 32px favicon and a LinkedIn avatar.

FIX → section 01: three real identity directions, pick one
Blocker

Claims without evidence

Every project is text + a number. A hiring manager can't tell shipped software from a well-written README. Nothing on the site shows the apps running — no video, no GIF, no screenshot, no dashboard.

FIX → sections 02–04: media-first project pages, dummy video slots now, real assets mined from repos
Major

Skills are implicit, not mapped

The home grid filters by capability, but no project page says "this demonstrates: agentic tool use, eval design, prompt versioning." Recruiters scan for skill keywords; make the mapping explicit and consistent, sourced from the ai-engineer-fit skills analysis.

FIX → skills-demonstrated chip row on every project page, one shared taxonomy
Major

No recruiter funnel

No contact CTA, no résumé, and zero social meta — a LinkedIn share of this site renders as a bare URL. The exact audience this site targets sees the weakest possible preview.

FIX → hero CTA row (Work · Résumé · Contact), OG/Twitter meta with a branded share card
Major

Case-study pages are half-built

Four of six are honest skeletons and the two flagships are prose-only. Repo links are empty. Fine for a walking skeleton — not for sending to a hiring manager.

FIX → phase 2 deep-reads every sibling repo and rewrites each page from what the code actually does
Minor

Hero is safe

Thesis + metric strip is exactly the template a designer would flag. It works, but the page's one memorable element shouldn't be a stat row. The signature move: make the identity itself alive (option A's cursor) and let one flagship visual anchor the fold.

FIX → keep the thesis, add CTA row + featured product visual once media exists
