# Fonts

IBM Plex Sans (variable, 400–600), IBM Plex Serif (400, 400 italic, 600) and
IBM Plex Mono (400), latin subset only, served from this origin.

IBM Plex is licensed under the SIL Open Font License 1.1 — https://github.com/IBM/plex.
These `.woff2` files are the latin-subset builds published by Google Fonts; the
`@font-face` rules that point at them live in `assets/css/fonts.css`.
